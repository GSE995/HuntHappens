# Меню игры

Меню появляется при запуске `Assets/Scenes/ForestPrototype.unity`. Во время охоты его открывает **Esc**. Две кнопки:

- **Продолжить** — закрывает меню и возвращает управление; повторный **Esc** делает то же самое. В текущем запуске состояние мира не меняется. После повторного запуска сцены загружается имеющееся локальное сохранение, а несохраняемые объекты создаются заново.
- **Начать заново** — сразу удаляет прогресс Hunt Happens, перезагружает текущую сцену и запускает охоту с **$15**. Отдельного подтверждения нет; подпись под кнопкой предупреждает о сбросе. Повторное нажатие в процессе перезапуска заблокировано.

Новая игра сбрасывает деньги, четыре улучшения, покупку тележки, инвентарь, припасы, улов, сроки сна переносимых крыс и возвращённых оленей. Перезагрузка сцены восстанавливает начальные здоровье и позицию игрока, животных, предметы и ловушки. Дополнительного аванса за оленье задание нет. Без сохранения или при повреждённом сохранении стартовый баланс также **$15**; существующий исправный кошелёк при «Продолжить» сохраняет свою сумму.

Пока меню открыто, курсор свободен, игровой ввод заблокирован, `Time.timeScale = 0`: движение, физика и таймеры на игровом времени стоят. При закрытии восстанавливается прежний масштаб времени. Для переносимых крыс срок пробуждения в UTC сдвигается на реальную длительность открытого меню: отсчёт приостанавливается с открытия до продолжения, а при выходе из игры этот сдвиг записывается. После закрытия приложения оставшийся срок сна, как прежде, идёт по реальному времени. Сброс игры удаляет эти сроки.

Esc в открытом магазине или рюкзаке сначала закрывает соответствующее окно; меню их не перекрывает. Tab, стрельба, покупки и взаимодействия во время меню заблокированы. Меню использует существующий EventSystem, отдельный Canvas поверх HUD и тот же шрифт и полевой стиль интерфейса.

Сохранение: ключ PlayerPrefs `HuntHappens.Shop.Progress.v1`. Сохраняются деньги, улучшения, владение тележкой, инвентарь и припасы, улов и сроки сна, идентификаторы возвращённых оленей. Положение игрока, здоровье, свободные предметы и расставленные ловушки не сохраняются. Чужие PlayerPrefs при новой игре не удаляются.

Основные файлы: `Scripts/UI/GameMenu.cs`, `Scripts/Interaction/InteractionHUD.cs` (создание меню рядом с HUD), `Scripts/Player/PrototypeInput.cs` (Esc и блокировка), `Scripts/Shop/ShopProgress.cs` (стартовые $15), `Scripts/Delivery/DeliveryManager.cs` (без аванса), `Scripts/SmallGame/RatHunting.cs` (пауза сроков сна). `ForestPrototype` включена в список сцен сборки для перезапуска.

## Проверка

Через Unity CLI в открытом редакторе: вызвать `HuntHappens.Editor.GameMenuChecks.Begin()` в Edit Mode; результат — `HuntHappens.Editor.GameMenuChecks.Result()`. Проверка использует отдельный тестовый ключ, восстанавливает его после выполнения и сравнивает настоящий снимок игрока до/после. Проверены в Unity 6000.6.6f1 начальные $15, пауза, сдвиг срока сна переносимой крысы, клики через EventSystem, продолжение, конфликт с рюкзаком, перезапуск сцены, сброс покупок, инвентаря, здоровья, задания и мира, повторная загрузка без аванса.

Ручная проверка: запустить сцену, нажать «Продолжить», открыть/закрыть меню Esc, затем после покупки или поимки животного нажать «Начать заново» и убедиться в балансе $15 и исходном состоянии мира. Для проверки сна взять спящую крысу, открыть меню дольше оставшегося срока и продолжить: время в меню не должно расходовать остаток сна.

Внешний вид меню при обычном старте проверен по Game View 1280×720 (`Logs/GameMenu.png`). Отдельно через виртуальную клавиатуру Input System проверен Esc: меню закрывается, пауза и блокировка снимаются, броска предмета нет. Компиляция прошла без ошибок и предупреждений; проверка меню завершилась `Game menu checks PASSED`. Ручной полный маршрут охоты и тест сна с настоящей пойманной крысой в рамках этой задачи не выполнялись.
