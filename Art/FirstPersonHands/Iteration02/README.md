## Просмотр в Blender

Открой CartoonHands_v02.blend, выдели Hands_Rig. В редакторе Dope Sheet переключись в Action Editor и выбери Action из списка. Space запускает воспроизведение. Диапазоны приведены ниже; установи соответствующий конец Timeline. В Pose Mode доступны все кости; Alt+H показывает скрытые кости, если они скрыты вручную. Исходная сцена открывается с Hands_Idle.

| Action | Кадры, 30 fps | Содержание |
| --- | --- | --- |
| Hands_Idle | 1–31 | Расслабленные пальцы, небольшое покачивание |
| Hands_Grab | 1–30 | Выдвижение и сгибание пальцев |
| Hands_Hold | 1–31 | Мягкое удержание, небольшое движение |
| Hands_Throw | 1–28 | Замах, выдвижение, раскрытие |
| Hands_Weapon | 1–31 | Различные углы запястий, захват и свободный указательный палец |
| Hands_Shoot | 1–18 | Небольшая отдача и возврат |
| Hands_Trap | 1–38 | Опускание, раскрытие и возврат |

Root → Forearm.L/R → Wrist.L/R → Palm.L/R → Thumb/Index/Middle/Ring/Little_01 → _02 → _03. Всего 37 костей. Суффиксы L/R сохраняют названия исходных объектов.

## Проверки и ограничения

У обеих исходных сеток по 21760 вершин, 21758 граней и ноль неманифолдных рёбер. Перевёрнутые нормали левой руки исправлены. Масштабы применены; координаты переведены в метры. Высота руки с коротким предплечьем примерно 28,6 см.

Веса нормализованы, максимум четыре влияния на вершину, непокрытых вершинами весов нет. Веса сглажены по соседям сетки, в том числе на переходе большого пальца в ладонь. Используется обычный linear skinning, совместимый с FBX. Исходное сглаживание Subdivision сохранено в Blender; в FBX экспортируется плотная базовая сетка без дополнительного подразделения, чтобы сохранить четыре влияния. В FBX около 87 тысяч треугольников на обе руки: это художественный прототип, не оптимизированный игровой бюджет.

Проверены все кадры Actions: конечные координаты без NaN/Inf, отсутствие вырожденных граней. Максимальное локальное растяжение ребра в крайней позе около 2,9 раза; это не гарантия отсутствия любых заломов при произвольных новых позах. На четырёх рендерах явных разрывов не видно. На семи основных позах BVH-проверка не обнаружила пересечений несмежных треугольников внутри каждой руки. Проверка не охватывает все возможные ручные позы и не является физической симуляцией контакта.

FBX импортирован обратно в чистую сцену Blender: две сетки, один Armature, 37 костей, семь Actions; движение сетки проверено для каждого импортированного Action. Масштаб скелета 1,1,1. Оси экспорта: -Z Forward, Y Up.

Позы удержания и оружия предварительные: пальцы не подогнаны под конкретный предмет, рукоятку или ствол. Для тесного кулака, точного контакта и больших углов запястья понадобится дополнительная настройка; текущая плотная сетка не заменяет ручную игровую ретопологию. Центр кадра остаётся свободным.

## Последующий импорт Unity

Unity-проект не открывался и не изменялся. Проверка в самом Unity ещё нужна.

Rig: Animation Type = Generic, Avatar Definition = Create From This Model, Root node = Root. Animation: Import Animation, затем проверить семь takes (FBX может добавлять к имени префикс Hands_Rig). Idle/Hold/Weapon можно использовать как циклы, остальные как одноразовые клипы. Apply Root Motion для этих анимаций не требуется — движения находятся на костях предплечий.

Для кожи создай URP/Lit: Base Color примерно #EAB895 (sRGB), Metallic 0, Smoothness около 0.5. Исходный Blender Base Color в линейном пространстве: (0.82, 0.48, 0.30). Подповерхностное рассеивание Blender через стандартный FBX/URP Lit автоматически не воспроизводится; вид зависит от освещения.

Документация Unity: https://docs.unity.com/en-us/engine/6000.6/manual/assets-and-media/asset-types/models/importing/generic-animations

## Повторная генерация

Из PowerShell:

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python '.\generate_rig.py'
```

Скрипт ищет исходник в соседней Iteration01. Переменные HANDS_SOURCE и HANDS_OUTPUT позволяют указать другой исходник и каталог результатов. Если Windows блокирует запись Blender в Documents, укажи HANDS_OUTPUT в доступном временном каталоге и затем перенеси готовые файлы.
